Instructions for AI agents working on this repository.

## Project Overview

**TABI** is an English-language curation site introducing Japan to the world.
Target audience: international tourists, Japan enthusiasts, potential visitors.

- Stack: Static HTML generated by PowerShell scripts
- Hosting: **GitHub Pages**, auto-deploys from `master` via `.github/workflows/deploy.yml`
- Language: **English** (all content and UI)
- Domain: `tabi.guide` (pending); currently served at `raynart.github.io/TABI`

## articles.json

A JSON **array** of article objects. Read and write it as UTF-8 — see the encoding
rule at the bottom of this file, which has been violated twice with real data loss.

### Article Schema

```json
{
  "id": "unique-slug-in-kebab-case",
  "title": "Article Title in English",
  "excerpt": "One or two sentences shown on cards and in the meta description.",
  "sections": [
    {
      "heading": "Section heading, sentence case",
      "paragraphs": ["The section body as one string."]
    }
  ],
  "category": "rules-etiquette",
  "tags": ["kyoto", "first-time"],
  "publishedAt": "2026-05-20",
  "updatedAt": "",
  "readingTime": 6,
  "heroImage": "https://raynart.github.io/TABI/assets/images/unique-slug-in-kebab-case.webp",
  "heroImageAlt": "Descriptive alt text for the hero image",
  "heroImageCredit": "AI-generated image by OpenAI",
  "affiliate": false,
  "affiliateLinks": [],
  "relatedIds": [],
  "author": "TABI Editorial"
}
```

### Field Rules

| Field | Rule |
|-------|------|
| `id` | Unique, kebab-case, URL-safe, no Japanese. Becomes `articles/<id>.html` and the hero image filename |
| `title` | English, no clickbait. Aim under ~70 chars; the longest current title is 81 |
| `excerpt` | **Required** — the build fails without it. 1-2 sentences, no "click here" |
| `sections` | **Required** — the build fails without it. Array of `{heading, paragraphs}`. Current articles run 5-9 sections |
| `sections[].heading` | Becomes an `<h2>` and a table-of-contents entry, so it must stand alone as a label |
| `sections[].paragraphs` | Array of strings, one `<p>` each |
| `sections[].image` | Optional `{src, alt, credit}`. `src` is a bare filename under `assets/images/`. **`alt` is enforced** — the build fails without it. A missing file is skipped with a warning |
| `category` | One of the 6 slugs below. **Enforced** — an unknown value aborts the build |
| `tags` | From the taxonomy below. **Enforced**. 2-3 is typical; do not exceed 5. A tag used by fewer than `thinTagThreshold` articles gets a `noindex` tag page |
| `publishedAt` | `YYYY-MM-DD`. Drives sort order, the sitemap and the RSS feed |
| `updatedAt` | `YYYY-MM-DD` or empty string `""` |
| `readingTime` | **Derived.** `generate-pages.ps1` computes it from the actual word count at 220 wpm and ignores this field. Keep it in sync, but the page is what the page says |
| `heroImage` | **Absolute** production URL under `assets/images/`. A relative path silently disables the `width`/`height` and `srcset` output |
| `heroImageAlt` | Required whenever `heroImage` is set |
| `heroImageCredit` | `AI-generated image by OpenAI` for GPT images. Disclosure of AI imagery is the point — do not drop it |
| `affiliate` | `true` only for `things-to-buy`. Gates the per-article `affiliateLinks` block |
| `affiliateLinks` | Array of `{"label", "url", "price"}`. Optional — see Monetization below |
| `relatedIds` | Existing article `id` values, 2-3. An id that does not exist is silently dropped |
| `author` | `"TABI Editorial"` |

Only four things are actually enforced by `generate-pages.ps1`: category, tags,
a non-empty `excerpt`, and non-empty `sections`. Everything else in this table is
convention, and breaking it fails quietly rather than loudly.

### Category Values (use exactly as written)

| Slug | Display Label |
|------|--------------|
| `before-you-go` | Before You Go |
| `rules-etiquette` | Rules & Etiquette |
| `getting-around` | Getting Around |

### Tag Taxonomy (use only these tags)

`accommodation` / `affiliate` / `budget` / `festival` / `first-time` / `food` /
`kyoto` / `language` / `luxury` / `nature` / `off-the-beaten-path` / `osaka` /
`practical` / `shopping` / `tokyo` / `tradition` / `transport`

Both lists are the ones in `site.config.json`. Adding a tag means adding it there
first; an ad-hoc tag aborts the build rather than producing a thin one-article
tag page.

## Content Guidelines

**Tone**: Warm, knowledgeable, insider — not a tourist pamphlet, not a Wikipedia article.

### Title
- Specific and benefit-driven: *"How to Climb Mt. Fuji Without Hiring a Guide"*
- Avoid vague: ~~"Things to Do in Kyoto"~~
- No emoji, no ALL CAPS

### Excerpt
- Lead with the most interesting fact or hook
- Never start with "In this article..." or "Learn about..."
- Should make the reader want to continue

### Sections
- One idea per section; the heading is a promise the paragraph has to keep
- Use concrete details: place names, prices in &yen;, train lines, hours
- First section: expand on the excerpt hook
- Last section: practical takeaway or call to action

### Things to Buy articles
- Always include actual prices (&yen; and approx USD)
- Explain *why* it is worth buying — not just what it is

## Monetization

Most monetization is automatic and does **not** belong in `articles.json`. The
contextual partner block and the ad slots are generated by `scripts/monetization.ps1`
from `site.config.json`, matched to each article by category and tags.

Set `affiliate: true` and fill `affiliateLinks` only when a specific product needs a
specific link — a named knife, a named whisky. The generator adds
`rel="nofollow sponsored"` and the above-the-fold disclosure; do not write link
markup into paragraph text.

See the Monetization section of `CLAUDE.md` for the rules that must not be undone.

## Encoding

`articles.json` has been corrupted twice by reading it with PowerShell's default
encoding, which is ANSI (CP932 here) in 5.1 and turns every em dash and curly quote
into mojibake.

- Read: `Get-Content ... -Raw -Encoding UTF8`
- Write: `New-Object System.Text.UTF8Encoding($false)`
- Never write Japanese, em dashes or curly quotes literally into a `.ps1` file — the
  scripts have no BOM and are read as ANSI. Use HTML entities.

## What NOT to Do

- Do not hand-edit generated HTML (`index.html`, `articles/*.html`, `categories/*.html`,
  `tags/*.html`, the static pages, `sitemap.xml`, `rss.xml`, `robots.txt`, `ads.txt`).
  Edit the generator and re-run it.
- Do not commit a build made with `TABI_SITE_URL` set — every URL would point at localhost.
- Do not write first-person reporting into an article or an excerpt: no "we visited",
  "we asked", "we tested", "in my experience". The content is AI-drafted and the site
  discloses that; claiming experience it does not have is a publisher-policy violation,
  and excerpts become the meta description that search engines display.
- Do not put a name in `publisher.name` that is not a real, contactable person.
- Do not add Japanese text to any content field (English-only site).
- Do not invent categories or tags outside the taxonomy.
- Do not set `affiliate: true` outside `things-to-buy`.
- Do not ship an affiliate link without `rel="nofollow sponsored"`, or an ad without
  its "Advertisement" label.

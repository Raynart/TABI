# TABI — Discover Japan

> Your guide to the real Japan — travel, culture, and the things worth bringing home.

English-language curation site for international visitors and Japan enthusiasts worldwide.

**Live site**: `raynart.github.io/TABI` (`tabi.guide` pending)  
**Hosting**: GitHub Pages — auto-deploys from `master` via `.github/workflows/deploy.yml`  
**Repo**: `github.com/Raynart/TABI`

---

## Stack

- Static HTML (generated by PowerShell scripts)
- No frameworks, no build tools, no Node.js required
- CSS custom properties design system
- GitHub Pages for hosting + CDN

## Getting Started

### Generate the site

```powershell
powershell -ExecutionPolicy Bypass -File ".\scripts\generate-site.ps1"
```

Run this after any change to `articles.json`, `site.config.json` or `scripts/`.  
Never hand-edit generated HTML files.

### Preview locally

Every page carries `<base href="…">`, so a production build cannot be previewed
locally — the browser would fetch CSS, JS and links from the live site. Build against
a local origin instead:

```powershell
$env:TABI_SITE_URL = "http://localhost:8080"
powershell -ExecutionPolicy Bypass -File ".\scripts\generate-site.ps1"
python -m http.server 8080
```

Re-run the generator **without** `TABI_SITE_URL` before committing.

## Monetization

Ad slots and affiliate blocks are configured under `monetization` in
`site.config.json` and stay **completely dormant until filled in** — an empty
`adsense.clientId` emits no ad markup at all, and a partner with no URL is never
rendered. See the Monetization section of `CLAUDE.md`.
